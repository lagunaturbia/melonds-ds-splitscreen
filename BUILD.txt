Extract Codigo_fuente in a new folder. From the extracted source directory,
in an MSYS2 UCRT64 or MINGW64 shell with GCC, Git, CMake and Ninja installed,
run bash COMPILAR.sh. The equivalent commands are:

    cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DENABLE_OPENGL=OFF -DENABLE_JIT=ON -DENABLE_LTO_RELEASE=OFF
    cmake --build build --parallel

The Windows core is build/src/libretro/melondsds_splitscreen_libretro.dll.
The accompanying core info is build/melondsds_splitscreen_libretro.info.
JIT support is built in. The runtime core option defaults to disabled.

Upstream source for this build:
- https://github.com/JesseTG/melonds-ds @ f394adbacb5722ee97c1b37c8064da9a25818310
- https://github.com/JesseTG/melonDS @ 16f127dbb587a73371827ce79689c5d237c4b59b

Each bundled dependency is an unmodified Git archive of the resolved
revision, except for the LocalMP changes in melonDS. Revision identifiers
for all dependencies are listed in SOURCE-REVISIONS.txt.

Splitscreen 1.3 is based on the stable splitscreen-v1.2 source (d931c25ee7fa24f7e373f6aa94bb7f6c65d030d6).
It adds pointer input and connects the existing threaded software 3D option to each DS.
